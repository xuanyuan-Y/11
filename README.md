# 掼蛋在线 - 在线多人掼蛋游戏

## 快速开始

### 1. 安装依赖
```bash
cd guandan-online
npm install
```

### 2. 启动服务器
```bash
npm start
```

### 3. 打开游戏
浏览器访问：`http://localhost:3000`

## 玩法说明

1. **创建房间**：输入昵称 → 点击"创建房间" → 获得6位房间号
2. **邀请朋友**：点击"复制邀请" → 发给朋友 → 朋友输入房间号加入
3. **准备开始**：所有人点击"准备" → 空位自动补机器人 → 自动开局
4. **2人即可开局**：不足4人时，空位由机器人补位

## 队伍分配
- 蓝队：1号位（南）+ 3号位（北）= 对家
- 红队：2号位（西）+ 4号位（东）= 对家

## 规则
- 使用两副牌（108张），每人27张
- 从打2开始，赢了升级（双上升3级、一三生2级、一四升1级）
- 逢人配：红桃级牌可当任意牌（除大小王）
- 牌型大小：天王炸 > 6张及以上炸弹 > 同花顺 > 5张炸弹 > 4张炸弹 > 普通牌型
- 打过A且队友不是末游即获胜

## 部署到公网（让朋友远程加入）

### 方案一：免费云平台（推荐）
1. 注册 [Render](https://render.com) 或 [Railway](https://railway.app)
2. 新建 Web Service，连接 GitHub 仓库
3. 构建命令：`npm install`，启动命令：`npm start`
4. 部署后获得公网网址，发给朋友即可

### 方案二：自己有服务器
```bash
# 安装Node.js后
npm install
npm start
# 默认端口3000，可用 nginx 反向代理
```

### 方案三：内网穿透（临时测试）
使用 ngrok / frp 等工具将本地3000端口映射到公网。

## 技术栈
- 后端：Node.js + ws（WebSocket）
- 前端：原生 HTML/CSS/JS（无框架，响应式）
- 游戏引擎：服务器端权威模式，防作弊

## 文件结构
```
guandan-online/
├── server.js          # WebSocket服务器 + 房间管理 + 游戏逻辑
├── engine.js          # 掼蛋游戏引擎（牌型识别、大小比较、AI）
├── package.json
├── README.md
└── public/
    ├── index.html     # 前端页面（首页/房间/游戏）
    ├── style.css      # 样式
    └── app.js         # 客户端逻辑
```
